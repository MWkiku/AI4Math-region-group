# 周精选归档

> 每周一份，由**轮值整理人**产出；这是「微信群讨论 → GitHub 沉淀」的唯一中转站。

## 命名

```
docs/周精选/YYYY-Www-周精选.md     例：2026-W43-周精选.md
```

（`Www` 为 ISO 周号；不确定周号就用 `YYYY-MM-DD` 命名，别纠结。）

## 怎么产出一份

1. 轮值整理人从微信群挑出本周**有价值的讨论**（不用全量，挑有信息量的），复制成文本；
2. 把文本 + `prompts/02-weekly-curation.md` 的提示词交给 AI；
3. AI 按 `templates/weekly-curation.md` 输出 → 存成本目录下的文件；
4. **相关成员确认**（在群里回一句「Q1 那个问题是我提的，表述对」即可）；
5. 确认后按文件里的提示开 Issue：任务 → 研究任务模板；卡点 → 卡点求助模板；可复用方法 → 能力包候选模板；
6. 纯经验 → `docs/` 下按主题建文件；本周收尾用 `checklist/weekly-checklist.md` 过一遍。

## 每份周精选必须写清

- 轮值整理人、确认人、日期范围；
- 哪些是 **AI 整理**、哪些经过**人工核实**；
- 「未验证 / 待人工判断」单独列一节——**没有这一节就不算完成**。

## 第一份从哪开始

第一次不用追求完整：本周群里只要产出了**一条**可追踪的问题或任务，就先把这份周精选建起来。**空白不丢人，讨论消失才丢人。**
