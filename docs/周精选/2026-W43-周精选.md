## 二、经验（可复用的方法、踩坑、配置）

1. **经验｜GitHub 仓库名只接受 ASCII**
   - 背景：新建仓库时用「AI4Math-区域小组」，网页建出来变成 `AI4Math--`。
   - 关键做法：仓库名只能用 `A-Za-z0-9._-`；中文只能作**显示名**写在 README / 描述里。API 把 `AI4Math-区域小组` 直接剥成 `AI4Math--`，可复现。
   - 适用范围：任何 GitHub 新建仓库。
   - 记录位置：`AGENTS.md` 第一节表格注、`README.md` 第一节。

2. **经验｜免费账号的私有仓开不了分支保护**
   - 背景：想给 `main` 加「要求 PR + 1 人 approve」。
   - 关键做法：`PUT /branches/main/protection` 与 `Rulesets` 都返回 403 `Upgrade to GitHub Pro or make this repository public`。私有仓 + 免费版 = 该功能不可用；要么升级 Pro，要么改公开，要么靠约定。
   - 适用范围：GitHub Free + Private 仓库。
   - 记录位置：`AGENTS.md` 第四节末条。

3. **经验｜git 不会自动走系统代理**
   - 背景：浏览器能开 GitHub，`git push` 报 `Empty reply from server`；直连 `github.com:443` 失败，但 `api.github.com` 通。
   - 关键做法：系统代理（`127.0.0.1:7897`）只对浏览器生效；git 需显式配置 `git config --global http.proxy http://127.0.0.1:7897`（https 同理）。
   - 适用范围：国内网络 + 代理客户端环境。
   - 记录位置：本条；撤销用 `--unset http.proxy`。

4. **经验｜GCM 授权会被「默认浏览器」打断**
   - 背景：`git push` 触发 Git Credential Manager，跳浏览器授权；中途换了默认浏览器，授权未完成，推送挂起。
   - 关键做法：等浏览器出现 `Authorize application` / `Authentication Succeeded` 页面并点完；凭据存入后（凭据管理器出现 `git:https://github.com`）后续免授权。
   - 适用范围：首次在这台机器上推任何私有仓。
