## 类型

提示词 / 规则 / 模板 / 检查项 / 工具链

## 判定标准（什么时候才算"改进生效"）

1. 有**具体的失败案例**作为触发（不是"感觉会更好"）；
2. 改完后**至少一个切片复测通过**，且记录在对应 Issue；
3. 同一类错误在后续两周**占比下降**；
4. 三者缺一，就只算"尝试过"，不算改进。

## 与能力包版本的关系

- 每次回写前，先在本表把「是否已验证有效」填成「是」；
- 回写时同步更新 `SKILL.md` 的 `version` 与 `CHANGELOG.md`；
- **未验证的改动不得写进能力包正文**（只留在这里）。
