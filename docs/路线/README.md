# docs/路线/ · 研究路线笔记归档

> 同一个问题常有多条路线并行（文献 / 证明 / 反例 / 实验）。每条路线**独立一个文件**，方便交叉核查与合并。

## 命名

```
docs/路线/#<Issue编号>-<关键词>.md      例：#7-逼近构造-Fp,q加权.md
```

## 怎么用

1. 从 `templates/研究路线笔记.md` 复制一份到本目录；
2. 填「基本信息」：关联 Issue、路线类型、负责人、系统配置（底座/模型/版本）；
3. 边做边写「过程要点」，**不要等做完再补**；
4. 第 6 节「失败 / 排除记录」**必填**——走不通也要写清为什么，这是最容易被浪费掉的信息；
5. 结论必须落在四档状态之一：猜想 / 部分证明 / 待核查 / 已完成内部核查。

## 两条底线

- **未核实的引用不许写成本组成果**：第 5 节专门用来登记「引用待核 / 步骤待核」；
- 同一问题不同路线的结论**互相矛盾时**，不要悄悄删掉一方，在两边都记下冲突点，交给人判断。
