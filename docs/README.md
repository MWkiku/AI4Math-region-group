# docs/ · 过程记录与经验

> 这里放**过程性记录**，不是正式成果。正式成果见仓库根与 `assets/`，成熟能力包走阶段 5 的入库流程。

## 放什么

| 子目录 / 文件 | 内容 |
|---|---|
| `周精选/` | 每周一份《周精选》，由轮值整理人产出 |
| `轮值整理人排班.md` | 轮值顺序、职责、交接规则 |
| `YYYY-MM-DD-<主题>.md` | 纯经验（可复用的做法、踩坑、工具配置），按主题建文件 |

## 两条规则

1. **经验要能被人复用**：写清「什么场景 / 怎么做 / 有什么坑」，只记「今天试了试」不算经验。
2. **AI 的归纳不等于事实**：周精选里由 AI 整理的内容，必须经过相关成员确认；标「未核实」的项不得被当成结论引用。
