# AI 替不了、必须由人完成的环节

> 清单里这些步骤，AI 只能提示和引导，不能代替。遇到时 AI 应明确停下，把动作交还给人。

## 一、账号与授权
- 注册、登录 GitHub / Zotero / 坚果云 / Overleaf / 模型服务；
- 模型订阅的**设备授权**：例如 ChatGPT 订阅登录时会给一个链接和一次性验证码，需本人在浏览器完成（验证码通常 15 分钟内有效），这一步所有 agent 工具都绕不过；
- 安装或首次运行时的「信任此文件夹」等系统确认；
- 仓库协作者邀请、权限设置、仓库公开/私有设置。

## 二、密钥与凭据
- API Key、密码、令牌的获取、填写与保管；
- AI 不应索要或代填密钥，只告诉人放在哪里、用什么环境变量 / 占位符；
- 提交代码前由人确认没有把密钥带进仓库。

## 三、学术判断（最终责任在人）
- 确定研究问题与研究路线；
- 判断一条数学结论、证明、计算是否成立；
- 判断 AI 给的文献引用是否真实、是否被曲解；
- 决定某条经验是否可收录为能力包、成熟度定到几级。

## 四、协作与发布
- 对外提交、合并到主分支、发布 Release 前的最终确认；
- 把成果在课程主页公开的决定；
- 组间争议、任务分工的最终协调。

## 五、AI 应该怎么配合
- 提前告知这些步骤会在什么阶段出现、需要准备什么；
- 提供清晰的操作指引，但把点击、登录、授权、确认留给人；
- 完成后引导人回到验证步骤（如 `pharos doctor` 无 FAIL、PR 已按模板填写）。

> 三铁律：无验证不自动；AI 贡献如实署名；最终判断与责任在人。
